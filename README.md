# Software Engineering Lab & Project Repository

A comprehensive repository containing software engineering laboratory assignments, architecture documentation, design artifacts, and application modules developed as part of coursework.

---

## 📌 Repository Overview

This repository demonstrates practical implementations of core Software Engineering methodologies, including modular programming, system design modeling, version control workflows, unit testing, and code refactoring.

### Key Highlights
- **Clean Architecture & Separation of Concerns:** Structured components separating business logic, state management, and user interfaces.
- **Game & Application Logic:** Modular scripts incorporating score computation, streak tracking, and interactive CLI/GUI interfaces.
- **Architectural & Design Artifacts:** Use case descriptions, component specifications, and workflow models adhering to standard software development life cycles (SDLC).
